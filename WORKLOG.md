# WORKLOG — Tibia Wheel of Destiny Optimizer

Architectural and modelling decisions (newest on top since D36) and open issues.

## Decisions (ADR-style, short)

| # | Date | Decision | Reason |
|---|------|----------|--------|
| D1 | 2026-11-18 | Stack: Vite 8 + React 19 + TypeScript + Tailwind CSS v4, Vitest for tests. | Static SPA is enough — no server required at runtime; fast dev loop; Tailwind fits a custom dark Tibian theme. |
| D2 | 2026-11-18 | Monster data is scraped **offline** by a Node script into a committed JSON file; the app ships static data. | tibiopedia.pl does not send CORS headers for browser use, and scraping a third-party site on every page view would be slow and impolite. |
| D3 | 2026-11-18 | One shared type contract in `src/types/index.ts`; each module exposes a small public API via its `index.ts`. | Lets the modules be developed in parallel without touching each other's files. |
| D4 | 2026-11-18 | The 5 classes are Knight, Paladin, Sorcerer, Druid, Monk. | Monk was added to Tibia in 2025 and has its own Wheel of Destiny. |
| D5 | 2026-11-18 | Priority slider is a single number 0–100 (0 = max DPS, 100 = max survivability). | Simplest possible mental model for the user and a single weight for the optimizer. |
| D6 | 2026-11-18 | Node.js 26 LTS installed portably in `%LOCALAPPDATA%\node-portable` (no admin install). | Node was not present on the dev machine. |
| D7 | 2026-11-18 | Wheel data source switched to the **official test-server planner** (test.tibia.com, upcoming update). Its WASM module (`skillgrid.js`) + `SkillwheelStringsJsonLibrary.json` are downloaded manually via a browser (Cloudflare blocks scripts) into gitignored `scripts/.cache/wod/`; a Node script runs the WASM and generates static JSON. | Most up-to-date data (new spells, gems, vessels). The CipSoft binary itself is never committed or shipped. |
| D8 | 2026-11-18 | Fight context: Hunt/Boss toggle (manual only); Avatar revelations valued only in Boss mode. Hunt style Solo / Team-lure (~4–6 mobs) / Team-box (~8–10 mobs); Boss ≈ single target. Baseline spell target counts from community data `spell-average-hits` (cached in `scripts/.cache/hunt-data/`). | Feature request; counts are estimates to be verified. |
| D9 | 2026-11-18 | Spell augments valued automatically by context: expected targets, spell element vs monster resistances, single-target vs area. | Feature request. |
| D10 | 2026-11-18 | Gems: user-owned gem inventory (quality, mods, grades I–IV) placed optimally into vessels + recommendations of best gems and most valuable mod-grade upgrades. | Feature request. |
| D11 | 2026-11-18 | UI language switch PL / EN. | Feature request. |
| D12 | 2026-11-18 | Realistic mitigation: depends on shielding/level; tiny at mid levels (a tested RP ≈ 1%). Target audience level 200–1500; HP preferred below ~1200 (EK) / ~1500 (RP) — must emerge from the math, not a hard rule. | Feedback from testing. |
| D13 | 2026-11-18 | Character inputs per vocation: EK level+melee+shielding; RP level+distance+shielding+mlvl; MS/ED level+mlvl; Monk level+fist+mlvl. | Needed for HP/mana, mitigation, spell damage and healing (e.g. RP mas san scales with mlvl). |
| D14 | 2026-11-18 | Flat "Damage and Healing" bonus valued relative to real per-hit damage/healing; consider Revelation Mastery gems that reach the next revelation stage (bigger flat bonus). Leech slices strongly devalued. | Gameplay knowledge. |
| D15 | 2026-11-18 | Multiple monsters per hunting spot with weights; best build + 2 alternatives; export-only planner code (incl. gems); gem/upgrade ranking by gain only (no cost). UI polishing postponed until functionality is accepted. | Design choice. |
| D16 | 2026-11-18 | **Hunt mode (AoE hunting) never values single-target spells** (all hunt styles); single-target spells count only in Boss mode. | Design rule. |
| D17 | 2026-11-18 | Damage model calibrated on a public damage-calculator API (`GET /meta/{vocations,stances,weapons,ammo,shields,perks,spells,creatures,charms}`, `POST /damage`). Datamined **offline** (polite: low rate, cached) into fitted per-spell formulas + perk effects committed as static data; no runtime dependency. | Community estimates are very good; avoid hammering a third-party API on every slider move. |
| D18 | 2026-11-18 | Defense valued as effective HP (EHP = HP / (1 − mitigation)); the arbitrary "spike" factor is removed. Gem slot 1 offers only Hit Points or Mitigation Multiplier; capacity and max mana have no value (potions + mana-leech imbuement assumed). Default resistance: physical unless the spot's monsters favour another. | Mitigation never beats HP on 200–1500 with real values. |
| D19 | 2026-11-18 | Real mitigation formula (no fight modes in the current game): ≈ shielding/100 % + shield/spellbook/quiver defense × vocation factor; calibration points: RP shielding 108 → 1.07 %; RP + shield 2.5 % total (shield part 1.28 %); ED 781 → 0.4 % shielding + 0.87 % spellbook. RP: quiver (hunt, bow) / crossbow (boss); mages: spellbook; EK: shield only in the shield rotation. | Character data + game source. |
| D20 | 2026-11-18 | Hunt styles removed (hunt targets = community averages; boss = 1). Damage based on rotation presets (`src/data/damage/rotations.ts`): engine auto-picks the best preset for the spot/build (user may override); revelation-unlocked spells (Divine Grenade, Executioner's Throw, Ice/Terra Burst, Spiritual Outburst; Avatars in boss) are added when the revelation is active; druid ultimate area spell (Eternal Winter / Wrath of Nature) chosen by resistance. Augments of spells outside the rotation (transit slices) have no value. | Gameplay knowledge. |
| D21 | 2026-11-18 | Forced spells: the user can force wheel augments of chosen spells (utility, e.g. Divine Dazzle, Mystic Repulse, Heal Friend). Healing gems excluded for ED/MS; for RP/EK/Monk valued on the defense side. Ballistic Mastery (bow: +4 % physical/holy pierce; crossbow: +10 % crit extra damage) and Positional Tactics (+3 distance 70 % of the time, else +3 holy/healing mlvl) valued exactly. | Gameplay knowledge + planner texts. |
| D22 | 2026-11-18 | community hunt target averages already include the wheel's area augment (Expanded Shape); without it a spell hits 0.5 fewer. Gem picks maximise overall damage; mods within 10 % of the chosen one's gain are listed as near-equal substitutes (`GemRecommendation.similar`); greater gem shown once with substitutes. | Gameplay knowledge (EK Front Sweep vs Fierce Berserk tie). |
| D23 | 2026-11-18 | A vessel holds only a gem the player added; unlocked vessels without an owned gem stay empty (never a recommended gem). The search values Gem Vessel slices only by the slice's own effects (+1 flat) and owned gems the new vessel can hold; gem recommendations stay advice (all qualities) and do not affect the allocation. | Priority 50 sorcerer chose "no revelation" because 3 vessel slices were worth ~20 pp EHP from assumed grade-IV gems. |
| D24 | 2026-11-18 | Stances (Vocation Adjustments 2026, TibiaWiki after the 7 July 2026 patch) are modelled and picked automatically per rotation plan by their build-independent value (damage vs the shared reference T0 + % EHP) at the user's priority. One stance per vocation; sorcerers one elemental + one aura. Elemental stances convert the next other-element spell: converted share = min(1, element casts / other casts). Serene uptime 80 %, 30 % of incoming damage from non-adjacent enemies (Divine Defiance dodge); Divine Defiance's healing magic level is valued through healing (e.g. Salvation). Monk presets carry their virtue. Elemental pierce capped at 2× sensitivity. | Feature request; values confirmed in-game (Q1–Q4). |
| D25 | 2026-11-18 | Base spell cooldowns follow TibiaWiki where the damage API datamine differs (`COOLDOWN_OVERRIDES`, applied on load): Shield Bash 4, Death Echo 6, Great Death Beam 6, Forked Glacier 6, Forked Thorns 6, Strong Ice Wave 4, Devastating Knockout 8, Mystic Repulse 8, Thousand Fist Blows 8, Intense Wound Cleansing 120 s. The rotation display includes the build's augment mods (cooldowns). | The DE – EW – DE – GDB rotation needs Death Echo's −2 s augment (DE was 4 s in the datamine). |
| D26 | 2026-11-18 | Gem steps: recommended gems are valued at grade I (a newly revealed gem); Fragment Workshop upgrades (+1 grade) are listed only once every unlocked vessel holds a gem. Revelation Mastery gems are valued by re-optimizing the wheel with the gem owned (greater, grade I): RM value = re-optimized objective with vs without the mod (beam width 16), plus the gem's basics; avatar RM is skipped outside boss mode; a full wheel keeps the static value. | Players without gems or with small gems need small steps; an RM gem changes the best wheel, not only the stage. |
| D27 | 2026-11-19 | Mod grades belong to the character: a mod has the highest grade any owned gem shows, in every gem (`withSharedGrades` on load and in `runOptimizer`; grade edits apply to all gems). Upgrades are per mod (gain summed over placed gems). Recommended gems carry the character's grades. Supreme spell gems are valued against the build's wheel augments on the other spells, so a cooldown gem in an already full preset rotation is worth ~0. Shared-cooldown ties (Ice/Terra Burst) prefer the spell the rotation casts. UI: "Add to my gems" on recommendations, "Upgrade" on upgrades. | Fragment Workshop grades apply to every gem; cooldown gems change little when the rotation is fixed and already the best. |
| D28 | 2026-11-19 | A gem fits only a vessel of its own quality (lesser → lesser, regular → regular, greater → greater); previously any gem fitted any vessel with the lower quality's slots active. | Small gems were placed into every vessel. |
| D29 | 2026-11-19 | Damage also buys sustain through imbuement life leech: +1 % damage adds leech share × HEAL_EHP × threat % EHP (offense weight += defense weight × that). Leech per hit follows the game (damage × leech × (0.1n + 0.9) / n); imbuement leech 50 % for EK/RP/monk (2× Powerful Vampirism), 25 % for ED/MS; the share is vs the main heal cast every turn. Gift of Life is halved while hunting. | Players use leech imbuements, so damage is also survivability. |
| D30 | 2026-11-19 | A gem recommendation needs room: when every unlocked vessel of its quality holds a gem, it is shown only as a replacement of the weakest one there (gain = difference), otherwise dropped. Recommendation sections per quality are collapsible. | With 2× the same gem placed, do not recommend a third if there is no room. |
| D31 | 2026-11-19 | Life leech from wheel nodes, augments and supreme mods is valued by the D29 model: +1 pp = leech EHP / imbuement leech (knight/paladin/monk 50, sorcerer/druid 25). Without gems, leech nodes on the path are now taken when worth it. A notice by the wheel says gems are missing and can change the build a lot. Mana leech unchanged. | Check whether leech nodes pay off without gems; suggest adding gems. |
| D32 | 2026-11-19 | Manual stance: Auto or a fixed stance set (incl. none) in the rotation panel; stored per vocation with the rotation prefs (localStorage, URL `st`). A manual stance applies to every plan, also over a preset's own stance. | Feature request. |
| D33 | 2026-11-19 | Monster weight up to 99 999 (step 1, wider field), so a weight can be kills per hour. | Feature request. |
| D34 | 2026-11-19 | Augment pairs whose value is mostly in stage II (e.g. Strong Ethereal Spear: I −2 s cooldown, II +380 % base damage) get up to 2 extra searches per plan, seeded with the cheapest paths to both slices; the best valid objective wins. The beam valued the first slice by stage I only and missed far pairs (boss paladin 600–800 pts: offense 25 → 56). | Boss paladin should take 2× Strong Ethereal Spear (SES > Ethereal Barrage > Divine Barrage/Caldera). |
| D35 | 2026-11-19 | Forced augments carry a stage: I = at least one slice (a note says when the engine also takes II because it pays off), II = both slices of the cheapest pair. Forced revelation stages (I–III) in a second column: stages below the forced one get a large penalty in the search tables and fail plan validity. Reach per stage (`revelationOptions`): greedy cheapest domain fill (RM slices +125, partial last slice) vs the budget with owned RM gems → ok / with a new RM gem of grade g / after upgrading the RM gem to g / out of reach; locked stages are disabled in the UI (vessel cost of the gem is not counted). Supreme mods sharing a name get the effect appended (Base Damage / Critical Damage / Cooldown / Healing). Crit stays 10 % / +50 %. | Feature request; crit: weapon proficiency to come. |
| D97 | 2026-11-22 | Item augments (a bonus to one spell, e.g. Moonsilver Trail Hood: Divine Barrage +8 % critical extra damage): imported from the TibiaWiki item infoboxes for all items and weapons (67 with augments), shown in the item list and applied by the engine: base damage, crit chance / extra damage and cooldown in the spell model, avatar cooldown in the avatar value, per-spell leech and base healing when choosing the worn items. Weapon augments join the proficiency loadout. | Augments are part of an item's value and change which item is best for a rotation. |
| D96 | 2026-11-22 | Epiphany on helmets that are not mage-exclusive (knight, paladin, monk): Intricate only; Basic and Powerful stay mage-helmet only. | D95 | 2026-11-22 | Charms are assigned on the built wheel: a first guess without the wheel, then the assignment is redone with the wheel's revelation stages, augments and flat damage, and the wheel is rebuilt while the assignment changes (at most two rebuilds). The listed gain is on the built wheel. Low Blow / Savage Blow now also raise the auto attack of a proficiency weapon (its recomputed auto attack dropped the charm crit). | Crit charms grow with the wheel's damage while flat charm hits do not, so charms chosen without the wheel favoured the flat ones. |
| D94 | 2026-11-22 | Every character has its own critical hit (5 % chance, +10 % extra damage, since the 2025 summer update); Strike adds 5 % / 5 %, 5 % / 15 %, 5 % / 40 % (Basic / Intricate / Powerful) on top. | D93 | 2026-11-22 | Charms: the player marks unlocked offensive charms (Wound, Enflame, Poison, Freeze, Zap, Curse, Divine Wrath, Overpower, Overflux, Carnage, Low Blow, Savage Blow) with their stage in a window opened from the paper doll; the engine assigns them to the spot's creatures (each charm once, one per creature, no slot limit) for the most damage and builds the wheel with them. Auto attacks roll charms on the main target only (area ammunition); Low Blow and Savage Blow crits apply to every target hit. Defensive and utility charms are not modelled. Values from TibiaWiki; details in engine.md / ui.md. | Charms change the damage the wheel works with (crit, extra hits); the best charm per creature depends on its HP, elements and the rotation. |

| D91 | 2026-11-21 | Priority slider with five fixed positions instead of free 0–100: DPS–survivability 100–0, 75–25, 50–50, 25–75, 0–100 (priority 0/25/50/75/100).
